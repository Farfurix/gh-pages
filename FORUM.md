# Форум Россия-Китай

## Описание

Добавлены две новые страницы для проекта форума Россия-Китай:

### 1. Форум (`/forum`)

Минималистичная главная страница форума в стиле russiachinaforum.com.

**Особенности:**
- Логотип и заголовок "Форум Россия-Китай"
- 4 кнопки навигации:
  - Приглашение (ведет на `/invitation`)
  - Программа пребывания гостя
  - Смета расходов
  - Информационно-справочные материалы
- Цветовая схема: светлая с синими акцентами (редкие красные элементы)
- Адаптивный дизайн
- Восточный орнамент из четвертинок кругов в сетке слева

**Файлы:**
- `src/components/Forum.jsx` — компонент страницы
- `src/components/Forum.css` — стили

### 2. Приглашение (`/invitation`)

Страница с официальным приглашением на форум.

**Особенности:**
- Официальный стиль документа
- Печать форума
- Детали мероприятия (дата, место, тема)
- Программа форума
- Кнопка для регистрации
- Светлый дизайн с красными акцентами

**Файлы:**
- `src/components/Invitation.jsx` — компонент страницы
- `src/components/Invitation.css` — стили

## Изменения в существующих компонентах

### Header (`src/components/Header.jsx`)
- Добавлен проп `simple` для упрощенного режима
- В простом режиме отображается только логотип и заголовок без контролов

### Footer (`src/components/Footer.jsx`)
- Добавлен проп `simple` для упрощенного режима
- В простом режиме отображается только копирайт

### Роутинг (`src/main.jsx`)
- Добавлен роут `/forum` → `<Forum />`
- Добавлен роут `/invitation` → `<Invitation />`

## Дизайн

**Тематика:** Россия-Китай

**Цветовая палитра:**
- Основной акцент: синий (#3498db, #2980b9)
- Дополнительный: красный (#e74c3c) - используется редко для выделения важных элементов
- Фон: светлый (#f5f7fa, #fafbfc)
- Текст: темно-серый (#2c3e50, #34495e)

**Стиль:**
- Минималистичный
- Простые формы
- Градиенты
- Анимации появления
- Восточный орнамент из четвертинок кругов в квадратной сетке на левой стороне страниц
  - Четвертинки кругов залиты синим цветом
  - Поворачиваются в разных направлениях
  - Образуют волнистые узоры
  - Полупрозрачные для элегантности

**Особенности:**
- Страница `/forum`: синий градиент в заголовке, орнамент из четвертинок кругов слева
- Страница `/invitation`: синий хедер, красная акцентная линия для блока делегации, орнамент из четвертинок кругов слева

## Запуск


- http://localhost:5173/gh-pages/invitation
